# Installation and validation

Requires Node.js >=22 and npm >=10.

## Clean install
```bash
npm ci
npm run check
```

The committed package-lock.json is required. The first lockfile is generated by the dedicated manual GitHub Actions workflow `Bootstrap F1 lockfile` and verified by `F1 checks`.

## Validation
- `npm run lint` uses TypeScript AST checks for explicit any, debugger, console.log, TypeScript suppression directives and tabs. This is a project-specific quality gate, not ESLint.
- `npm run typecheck` performs strict TypeScript typechecking.
- `npm test` builds and runs Node's automated tests.

## Deliberate limit
The Next.js MCP server remains a placeholder until F2 implements transport, authentication and endpoints. Do not deploy an unauthenticated endpoint.
