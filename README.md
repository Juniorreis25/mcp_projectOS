Sistema pessoal de desenvolvimento assistido por IA, distribuído por um servidor MCP remoto (Vercel), com skills portáveis entre diferentes IDEs e agentes.

## Princípios

- Catálogo de skills versionado e independente do cliente.
- Execução local de alterações e testes nos ambientes autorizados.
- Aprovações explícitas para operações sensíveis.
- Progresso somente concluído mediante evidências verificáveis.
